# Medical Text Simplification — CIE 553 NLP Project

A comparative study of four automatic biomedical text simplification systems evaluated on SARI, BLEU, and FKGL.

## Systems

| System | Approach |
|--------|----------|
| Rule-Based | Dictionary jargon substitution (507 entries) |
| T5-Small | Fine-tuned on PLABA + Cochrane |
| SciFive | Biomedical T5 fine-tuned identically to T5-Small |
| Hybrid | Rule-based substitution → T5-Small generation |

## Results

| System | SARI | BLEU | FKGL Δ |
|--------|------|------|--------|
| Rule-Based | 10.97 | 5.96 | −1.31 |
| T5-Small | 33.41 | 7.92 | −5.41 |
| SciFive | 33.40 | 7.92 | −5.41 |
| Hybrid | 29.48 | 6.37 | −3.84 |

## Notebooks

| Notebook | Purpose |
|----------|---------|
| `01_data_preprocessing.ipynb` | Dataset loading, cleaning, train/val/test split |
| `02_rule_based.ipynb` | Rule-based system inference + evaluation |
| `03_t5_finetune.ipynb` | T5-Small and SciFive fine-tuning |
| `04_hybrid.ipynb` | Hybrid pipeline inference + evaluation |
| `05_evaluation.ipynb` | **Demo notebook** — run this to see all results |

## How to run the demo

```bash
git clone <repo-url>
cd <repo>
pip install -r requirements.txt
jupyter notebook notebooks/05_evaluation.ipynb
```

Run all cells. No GPU or Google Drive required.
